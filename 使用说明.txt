============================================================
  🦐 虾铺开张中 · 产驹数据库 —— 使用说明
============================================================

这个文件夹里有什么：
  index.html      —— 网站本身（双击就能用浏览器打开）
  data.js         —— 产驹数据（自动生成，别手动改）
  thisweek.js     —— 本周出马数据（自动生成，别手动改）
  updates.js      —— 更新日志（自动生成）
  sire-info.js    —— 店长/种马资料（★改店长信息就改这里）
  corrections.js  —— 数据修正（★改错误数据就改这里）
  使用说明.txt     —— 你现在看的这个

------------------------------------------------------------
一、看效果
------------------------------------------------------------
  双击 index.html，浏览器打开后一进来就是「首页」。
  首页有：
    · 店长 エピファネイア 和 儿子 エフフォーリア 的资料卡
    · 搜索框：输入任意马名 / 英文名，回车跳到产驹列表看结果
    · 三张导航卡：产驹列表 / 本周出赛 / 更新日志
    · 「信息更新」：显示最近数据更新的记录
    · 「反馈 / 报错」按钮：弹窗引导去 GitHub 提交

  点「产驹列表」进去后：
    · 顶部搜索：马名 / 英文名 / 母名 / 母父 / 牧场 / 马主 / 调教师
    · 种马 / 性别 / 毛色：点按钮筛选
    · 只看已获胜：勾选只看赢过比赛的马
    · 表格 / 卡片切换、点表头排序、点马名看详情

------------------------------------------------------------
二、★ 怎么快速修改错误数据（重点，用这个！）
------------------------------------------------------------
  数据是自动从 netkeiba 抓的，偶尔会有错。
  改错不需要动 data.js，只改 corrections.js 这个文件
  （自动更新不会覆盖它）。

  步骤：
  1. 找到出错的那匹马，点开它的「详情页」
     这时浏览器地址栏会变成 #/horse/一串数字，
     那串数字就是这匹马的 ID（把它记下来）

  2. 用记事本打开 corrections.js
     在大括号 { } 里面写一行，格式是：
       "马匹ID": { "字段名": "正确值" },
     比如某匹 ID 为 2024105865 的马毛色错了，就写：
       "2024105865": { "color": "鹿毛" },

  3. 保存文件后刷新网页（按 F5），错误就被覆盖了

  常用字段名（改哪填哪）：
    name 马名    en 英文名    sex 性别（牡/牝/セ）
    color 毛色   bd 生日     rec 成绩（比如 "15战6胜"）
    trainer 调教师   farm 牧场   owner 马主   bms 母父

  可以一次改多匹、改多个字段，中间用逗号隔开。
  比如同时改两匹：
    "2024105865": { "color": "鹿毛", "rec": "15战6胜" },
    "2022104893": { "trainer": "某调教师" },

------------------------------------------------------------
三、★ 怎么改首页店长资料
------------------------------------------------------------
  首页那两张资料卡（店长、儿子）来自 sire-info.js。
  想改生日、成绩、简介，用记事本打开 sire-info.js 改文字就行。

------------------------------------------------------------
四、数据是怎么来的（自动更新）
------------------------------------------------------------
  网站数据由 GitHub 上的脚本每周自动抓取 netkeiba 并部署，
  你平时什么都不用做。
  想手动触发更新，去 GitHub 仓库 Actions 标签里手动 Run workflow。

------------------------------------------------------------
五、反馈 / 报错
------------------------------------------------------------
  点首页的「反馈 / 报错」按钮，或直接打开：
    https://github.com/effiphane/epimome/issues/new
  提交即可，我会看到。

小提示
------------------------------------------------------------

  · 改错误数据 → 改 corrections.js
  · 改店长资料 → 改 sire-info.js
  · 遇到问题，把报错或截图发给我
