============================================================
  🦐 虾铺开张中 · 产驹数据库 —— 使用说明
============================================================

这个文件夹里有什么：
  index.html      —— 网站本身（双击就能用浏览器打开）
  data.js         —— 产驹数据（自动生成，别手动改）
  thisweek.js     —— 本周出马数据（自动生成，别手动改）
  updates.js      —— 更新日志（自动生成）
  sire-info.js    —— 店长/种马资料（★改店长信息就改这里）
  corrections.js  —— 数据修正（★改错误数据就改这里）
  使用说明.txt     —— 你现在看的这个

------------------------------------------------------------
一、看效果
------------------------------------------------------------
  双击 index.html，浏览器打开后一进来就是「首页」。
  首页有：
    · 店长 エピファネイア 和 儿子 エフフォーリア 的资料卡
    · 搜索框：输入任意马名 / 英文名，回车跳到产驹列表看结果
    · 三张导航卡：产驹列表 / 本周出赛 / 更新日志
    · 「信息更新」：显示最近数据更新的记录
    · 「反馈 / 报错」按钮：弹窗引导去 GitHub 提交

  点「产驹列表」进去后：
    · 顶部搜索：马名 / 英文名 / 母名 / 母父 / 牧场 / 马主 / 调教师
    · 种马 / 性别 / 毛色：点按钮筛选
    · 只看已获胜：勾选只看赢过比赛的马
    · 表格 / 卡片切换、点表头排序、点马名看详情

------------------------------------------------------------
二、★ 怎么快速修改错误数据（重点，用这个！）
------------------------------------------------------------
  数据是自动从 netkeiba 抓的，偶尔会有错。
  改错不需要动 data.js，只改 corrections.js 这个文件
  （自动更新不会覆盖它）。

  步骤：
  1. 找到出错的那匹马，点开它的「详情页」
     这时浏览器地址栏会变成 #/horse/一串数字，
     那串数字就是这匹马的 ID（把它记下来）

  2. 用记事本打开 corrections.js
     在大括号 { } 里面写一行，格式是：
       "马匹ID": { "字段名": "正确值" },
     比如某匹 ID 为 2024105865 的马毛色错了，就写：
       "2024105865": { "color": "鹿毛" },

  3. 保存文件后刷新网页（按 F5），错误就被覆盖了

  常用字段名（改哪填哪）：
    name 马名    en 英文名    sex 性别（牡/牝/セ）
    color 毛色   bd 生日     rec 成绩（比如 "15战6胜"）
    trainer 调教师   farm 牧场   owner 马主   bms 母父

  可以一次改多匹、改多个字段，中间用逗号隔开。
  比如同时改两匹：
    "2024105865": { "color": "鹿毛", "rec": "15战6胜" },
    "2022104893": { "trainer": "某调教师" },

------------------------------------------------------------
三、★ 怎么改首页店长资料
------------------------------------------------------------
  首页那两张资料卡（店长、儿子）来自 sire-info.js。
  想改生日、成绩、简介，用记事本打开 sire-info.js 改文字就行。

------------------------------------------------------------
四、数据是怎么来的（自动更新）
------------------------------------------------------------
  网站数据由 GitHub 上的脚本每周自动抓取 netkeiba 并部署，
  你平时什么都不用做。
  想手动触发更新，去 GitHub 仓库 Actions 标签里手动 Run workflow。

------------------------------------------------------------
五、自己调整外观（颜色 / 字体 / 圆角）
------------------------------------------------------------
  外观全部在 index.html 一个文件里，用记事本打开就能改。
  改之前先复制一份 index.html 备份（改名 index.备份.html），改坏能还原。

  ★ 最常用：改颜色（第 8~26 行的 :root{ } 里）
      --bg     页面底色        --paper  卡片底色
      --ink    正文文字色      --muted  次要文字（灰）
      --line   分隔线色        --brand  主色（墨绿）
      --brand2 主色深一档      --gold   点缀金
      --serif  标题字体
    改一个色值，全站跟着变。

  ★ 各部分位置（在文件里搜 "=====" 就能跳到）：
      第 38 行   ===== 顶部       标题栏、返回按钮
      第 96 行   ===== 工具栏     筛选标签
      第 144 行  ===== 表格       产驹列表表格
      第 180 行  ===== 卡片       卡片视图
      第 229 行  ===== 本周出马   出赛表格、名次色块
      第 259 行  ===== 首页       大标题、种马卡、各栏目
      第 365 行  ===== 详情页     血统、战绩
      第 438 行之后            页面上的文字内容

  ★ 常见微调：
      标题字号：.home-hero h1{ font-size:54px }（首页）
                h1{ font-size:36px }（列表页顶部）
      悬停放大幅度：搜 scale(1.02)，改成 1.05 更明显
      全部变圆角：全文件替换 border-radius:2px → 8px
      名次色块颜色：搜 rank-badge（金色 / 银色 / 铜色 / 深灰）

  ★ 改完保存，浏览器按 Ctrl + F5 强制刷新就能看到。
  ★ 想边改边看：按 F12 → 左上角箭头 → 点页面元素 → 右侧直接改数值。

------------------------------------------------------------
六、添加中文资讯 / B 站视频
------------------------------------------------------------
  · 中文资讯 → 编辑 news.js，按文件里的格式加一条：
      { date: "2026-10-23", title: "标题", source: "来源", url: "链接" },
  · B 站视频 → 编辑 videos.js，填 bvid（BV 开头那串）：
      { title: "标题", bvid: "BV1xx411c7mD", up: "UP主" },
  两个文件里都有注释示例，复制改一下就行。
  · 内容为空时，首页对应栏目会自动隐藏。
  · 保存后刷新网页即可看到。

  · 分享卡：打开任意马的详情页，点「生成分享卡」，
    会下载一张 1080×1350 的 PNG（纸感排版，含照片、战绩、适性统计），
    可以直接发小红书 / 微博。
